# Operational Runbook: LinkedIn Easy Apply Automation

> **Target Platform:** LinkedIn (Easy Apply Requisitions)  
> **Adapter Class:** LinkedInAdapter / EasyApplySaga  
> **Capability Tier:** Level 3 (Stealth Browser Multi-Step Modal Saga)  
> **Default Daily Cap:** 25 submissions / 24 hours  

---

## 1. Prerequisites & Account Safety

LinkedIn strictly enforces behavioral heuristics and rate limits. JoBot executes Easy Apply through a **Deterministic Multi-Step Modal Saga** with human-like Bezier cursor physics and deliberate pacing.

### Prerequisites
1. **Live Browser Flag**: Live browser execution must be enabled:
   ```bash
   export JOBOT_RUN_LIVE_BROWSER=1
   ```
2. **Session Cookies**: Log into LinkedIn interactively:
   ```bash
   jobot login linkedin
   ```
   Cookies and session storage are saved to `~/.jobot/sessions/linkedin/state.json`.

---

## 2. Scraping & Requisition Discovery

Search LinkedIn postings using the built-in scraper engine:
```bash
jobot scrape linkedin --keywords "Senior Python Engineer" --location "Remote" --limit 30 --save
```

---

## 3. Easy Apply Modal Saga Execution

### Multi-Step Modal Progression
When `jobot apply <JOB_ID> --approve` runs against a LinkedIn Easy Apply requisition:

1. **Modal Launch**: Locates and clicks the Easy Apply button.
2. **Contact Info Step**: Pre-fills phone number and email from `CandidateTruthStore`.
3. **Resume Step**: Attaches tailored PDF generated by `DocumentTailor`.
4. **Custom Screening Questions**:
   - Numeric fields (e.g. Years of Python experience): answered via `QAEngine`.
   - Radio buttons / Dropdowns (e.g. Will you require sponsorship?): answered from work authorization facts.
   - Text prompts: generated by `QAEngine` and sanitized by `CandidateGroundingVerifier`.
5. **Review Step**: Inspects summary modal before final dispatch.
6. **Submission & Verification**:
   - Clicks Submit application.
   - Waits for confirmation banner ("Application sent").
   - Captures DOM snapshot and PNG confirmation screenshot to `~/.jobot/evidence/`.

---

## 4. Policy Caps & Cooldowns

- **Daily Cap**: Never exceed 25 applications per day on LinkedIn to maintain account trust scores.
- **Inter-Application Delay**: Enforces 45s–120s randomized jitter between applications.
- **Circuit Breaker**: If LinkedIn presents a CAPTCHA or PIN checkpoint, the circuit trips `OPEN` immediately and dispatches an alert.
