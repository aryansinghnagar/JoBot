Executive SummaryJoBot is an **Autonomous Job Application Operating System (AJOS)** — a local-first,privacy-preserving, human-governed personal assistant for job discovery, applicationtailoring, form automation, and career tracking.### The ProblemThe repository contains **85,016 lines of planning documentation** across 5+ files(`agent.md`, `plan.md`, `job\_application\_automaton\_plan.md`, `unified\_master\_plan.md`,and 5 implementation contracts) but only **3,770 lines of Python** — a **22:1documentation-to-code ratio**. The implementation is a **stub warehouse**:- Every portal adapter is a no-op returning hardcoded data- Every `verify\_submission()` returns `True` without any network/browser action- 9 subsystems (QAEngine, PolicyEngine, CircuitBreaker, TraceLogger, AlertDispatcher,  EightTierMemorySystem, BehavioralMimicry, ProxyManager, CaptchaSolver) are fully  implemented but **never invoked** from the pipeline- The "100% test suite passing" claim is false (26 pass, 1 fail)- The "release-1.0 complete" claim is false### The FixThis plan converts the liability (documentation without working code) into a workingsystem through **6 phases over 28 weeks**, prioritizing:1. **Truth first** — eliminate all fake/stub behavior2. **Closed loop** — goal → task graph → execution → verification → memory → visibility3. **Cutting-edge free tech** — open-source alternatives over paid services4. **Measurable results** — no feature is "done" until verified end-to-end### Key Principle> "If a choice arises between a beautiful description and a working system,> choose the working system. Between a clever architecture and an observable one,> choose the observable one. Between an unverified claim and a measurable result,> choose the measurable result."> — `agent.md`---## 2. Vision & Governing Doctrines### 3.1 Product VisionJoBot is a **local-first personal assistant** that helps a job seeker:1. Maintain a comprehensive and accurate professional profile2. Discover and normalize relevant job opportunities3. Identify duplicate, stale, suspicious, or unsuitable listings4. Score jobs against explicit eligibility rules and user preferences5. Tailor résumés and application materials **without inventing facts**6. Answer application questions using approved, evidence-backed information7. Operate supported application forms up to a final review checkpoint8. **Stop before submission** in its initial release9. Track application status, correspondence, interviews, and follow-ups10. Learn from corrections without silently changing sensitive behavior### 3.2 Non-Negotiable Design Bets (from `agent.md`)- **Closed Loop:** goal → task graph → execution → verification → memory → visibility → learning- **Bias toward working systems** over beautiful descriptions- **Observable over clever** — if you can't see it, it doesn't exist- **Transparent state** over hidden memory tricks- **Measurable results** over unverified claims- **Durable execution** — survive crashes, restarts, model swaps- **Economics** — choose cheaper methods when sufficient, expensive when justified- **Governance** — know when not to act, when to ask, when to escalate### 3.3 Architecture Doctrine- **Hybrid Control Plane:** REST for CRUD/dashboards + WebSockets for live updates- **Hub-and-Worker:** Durable queueing in hub, tool execution on workers- **SQLite WAL** for single-server control plane (upgrade to Postgres only at scale)- **State Split:** Operational indexing in DB, canonical project state in Markdown/files- **Pull-based task claiming** every 30 seconds (default)- **Human-in-the-loop** for all irreversible actions### 3.4 Privacy Doctrine- **Local-first:** Must function without cloud, without LLM, without network- **No data exfiltration:** PII never leaves device without explicit user action- **AI as assistant, not authority:** LLMs enhance but never override user data- **Encryption at rest:** All credentials and PII encrypted via PyNaCl- **End-to-end encryption** for any cloud sync (relay)- **Human-governed:** All submissions require explicit approval---## 4. Derive encryption key from master password using scrypt&#x20;       salt = self.\_get\_or\_create\_salt(vault\_path)&#x20;       self.\_key = scrypt.kdf(&#x20;           master\_password.encode(),&#x20;           salt,&#x20;           key\_size=32,&#x20;           opslimit=scrypt.OPSLIMIT\_INTERACTIVE,&#x20;           memlimit=scrypt.MEMLIMIT\_INTERACTIVE,&#x20;       )&#x20;       self.\_box = nacl.secret.SecretBox(self.\_key)&#x20;   def store(self, key: str, value: str) -> None:&#x20;       """Encrypt and store a credential."""&#x20;       encrypted = self.\_box.encrypt(value.encode())&#x20;       self.\_write\_to\_keyring(key, encrypted)&#x20;   def retrieve(self, key: str) -> str:&#x20;       """Decrypt and return a credential."""&#x20;       encrypted = self.\_read\_from\_keyring(key)&#x20;       return self.\_box.decrypt(encrypted).decode()&#x20;   def store\_session(self, site: str, cookies: dict) -> None:&#x20;       """Store browser session cookies for reuse."""&#x20;       import json&#x20;       self.store(f"session:{site}", json.dumps(cookies))```#### PII Masking for LLM Calls```python\# src/jobot/security/pii\_masker.pyimport reclass PIIMasker:&#x20;   """Mask PII before sending to external LLMs."""&#x20;   PATTERNS = {&#x20;       "phone": r"\\+?\\d{10,13}",&#x20;       "email": r"\\b\[A-Za-z0-9.\_%+-]+@\[A-Za-z0-9.-]+\\.\[A-Z|a-z]{2,}\\b",&#x20;       "aadhaar": r"\\b\\d{4}\\s?\\d{4}\\s?\\d{4}\\b",&#x20;       "pan": r"\\b\[A-Z]{5}\\d{4}\[A-Z]\\b",&#x20;   }&#x20;   def mask(self, text: str) -> tuple:&#x20;       """Replace PII with tokens. Returns masked text and mapping."""&#x20;       mapping = {}&#x20;       for pii\_type, pattern in self.PATTERNS.items():&#x20;           matches = re.findall(pattern, text)&#x20;           for i, match in enumerate(matches):&#x20;               token = f"\[{pii\_type.upper()}\_{i}]"&#x20;               text = text.replace(match, token)&#x20;               mapping\[token] = match&#x20;       return text, mapping&#x20;   def unmask(self, text: str, mapping: dict) -> str:&#x20;       """Restore PII from tokens."""&#x20;       for token, original in mapping.items():&#x20;           text = text.replace(token, original)&#x20;       return text```### 9.3 Observability (OpenTelemetry + SigNoz)**Why SigNoz:** Free, open-source alternative to Datadog.
